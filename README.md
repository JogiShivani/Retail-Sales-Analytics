# Retail Sales Analytics (Python + SQL + Power BI)

## Business Problem

Retail businesses generate large volumes of sales transactions across products, categories, and regions. Management needs a centralized analytics solution to monitor sales performance, identify top-performing products, track regional trends, and support data-driven business decisions.

## Project Objective

Build an end-to-end retail analytics project using Python, SQL, and Power BI by creating datasets, performing data analysis, and developing an interactive dashboard.

## Project Workflow

### 1. Data Generation (Python)

* Generated retail datasets for customers, products, and orders.
* Used Python and Pandas to create realistic sales data.
* Exported datasets as CSV files.

### 2. Data Analysis (SQL)

* Imported datasets into MySQL.
* Performed sales aggregation and business analysis.
* Identified top products, profit trends, and regional sales performance.

### 3. Data Visualization (Power BI)

Built an interactive dashboard containing:

* Total Sales
* Total Profit
* Total Orders
* Average Order Value
* Sales Trend (2025)
* Top 10 Products by Sales
* Sales Distribution by Category
* Top States by Sales
* Interactive filters for Category, State, and Order Date
 
 
### 4. Excel / Google Sheets

* Imported and explored retail sales data.
* Created pivot tables for business analysis.
* Analyzed Sales by Category.
* Analyzed Sales by State.
* Identified Top Products by Sales.
* Created charts to summarize key business insights.
* Prepared data for SQL and Power BI reporting.
